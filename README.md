# Mengede - Addis Ababa Transit Network
A modern, full-stack transit navigation and administration platform for Addis Ababa. The application maps public transport terminals, operational routes, and fares, featuring a robust public-facing interactive map and a secure, rate-limited administrative backend for managing geolocation data.
